Security & Desktop Node Launch Guide (100% Open-Source & Safe)

Variable Coin Protocol is an independent, open-source blockchain daemon. Because standalone binaries lack commercial digital certificates, Windows Defender or antivirus programs may show standard security prompts upon initial launch. This is a false positive and completely safe.

Recommended Launch Configuration:
1. Windows SmartScreen: If prompted with "Windows protected your PC", click "More info" → "Run anyway".
2. Windows Firewall: When the network prompt appears, check BOTH boxes (Private networks and Public networks) and click "Allow access". If skipped or cancelled, the node automatically activates Bitcoin-style outbound sync to maintain full mining and ledger capabilities without interruption.

Variable Coin Protocol (VCP)

        
Installation Permissions, Infinite Variable Logic & Mini User Guide

        
        

            
1. Desktop Node Download & Security Permissions

            
Variable Coin Protocol runs as a sovereign peer-to-peer (P2P) node. When launching the standalone desktop package for the first time, please grant the following system permissions so the node can synchronize properly:

            
    
                
  • Windows SmartScreen & Antivirus Notice: Because this is an independent open-source cryptographic binary without a commercial corporate certificate, Windows may display a "Windows protected your PC" prompt. Click "More info" and then "Run anyway".
    • 
                
  • Firewall Network Access: When prompted by Windows Firewall, select both Private networks and Public networks, then click "Allow access". This enables direct P2P block synchronization and mining broadcasts.
    • 
            


            
2. The Infinite Variable Architecture & 1-99 Rule

            
    
                
  • Infinite Variable Logic: Instead of static difficulty or heavy memory footprints, the protocol operates across an Infinite Variable space that rotates every 24 hours.
    • 
                
  • 1 to 99 Active Scaling: Each node is assigned a dynamic 1-to-99 operational ratio every 24 hours based on storage safety and thermal conditions. All blocks remain permanently archived on disk while active memory scales between 1% and 99%.
    • 
            


            
3. Application Settings & Mini User Guide

            
    
                
  • Wallet & Inventory Hub: Generate a new 256-bit SECP256k1 key pair or restore an existing wallet using your 64-character private key. Generated keys are displayed solely in the wallet box without auto-filling other sections.
    • 
                
  • Mining Hub: Select either SHIELD COIN or MAIN COIN and dispatch the miner. The mining output displays the Asset Type, Block Number, Mined Reward/Impact Power, and your 1-99 Mining Power Position.
    • 
                
  • Transfer & Send Hub: Transfer Main Coins or Shield Coins to any peer address. When sending Shield Coins, you can view how many units you hold in each bracket (99-70, 70-50, 50-30, 30-10, 10-1, <1) and specify the exact Impact Power and quantity to transfer. If the exact power is not available, the system reports the closest available token power in your wallet.
    • 
                
  • Variable Coin Command Center: Burn Shield Coins from a chosen power tier to trigger protocol actions:
                    
      
                        
    • PEG PRICE / BOOST PRICE / DISCOUNT PRICE: Stabilizes or adjusts valuation according to supply and demand. You can select Personal (applies to your wallet) or Global (applies network-wide).
      • 
                        
    • BURN SUPPLY / EXPAND CAPACITY: Permanently burns Main Coin supply or expands maximum network capacity. These supply actions always operate Globally across the entire protocol.
